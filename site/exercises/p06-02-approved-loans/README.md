## Task

The credit team wants every **APPROVED** loan of **at least 5,00,000** rupees, with the customer's name.

Return exactly three columns, in this order: `loan_id`, `full_name`, `amount`.

- Largest amount first.
- When amounts are equal, smaller `loan_id` first.

The tables `customers` and `loans` are created for you before your query runs. Their definitions are under "Tables created for you" below, or just run `SELECT * FROM loans;` first.

Only the **last statement** in your file is checked, so you can keep exploratory queries above it.
